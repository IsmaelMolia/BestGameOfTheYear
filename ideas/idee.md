Projet : Civ-Like-Pygame

L'objectif est de créer un jeu de stratégie 2D au tour par tour, un peu dans le même genre que civilization 6. 
Ce serait donc un jeu 4X (Explore, Expand, Exploit, Exterminate) avec un map en forme de grille hexagonale et plusieurs mécaniques qu'on retrouve dans ce genre de jeu.

Ce que le joueur pourra faire : 
- [X] accéder à un menu pour gérer des paramètres d'affichage, des créations de parties et des gestions de sauvegardes
- [X] pouvoir voir une map avec un système de caméra qui permet de se déplacer et de zoomer/dézoomer
- [X] pouvoir déplacer des unités/bâtiments et utiliser leurs actions
- [X] pouvoir inspecter les unités/bâtimentes
- [X] avoir différents affichages de map (empire, ressources, fog of war...)
- [X] pouvoir mettre le jeu en pause et avoir une liste de commandes
- [X] pouvoir passer des tours
- [ ] pouvoir créer des bâtiments à l'aide d'un menu BUILD
- [ ] pouvoir gérer une ville et créer des unités à l'aide d'un menu CITY
- [ ] pouvoir récolter des ressources stratégiques
- [ ] pouvoir affronter d'autres joueurs gérés par une IA basique
- [ ] pouvoir avancer dans un arbre technologique

Élements qui pourraient rendre le projet intéressant :
- [~] Apprendre à bien structurer un gros projet de ce type (jeu vidéo 2D)
- [X] Réussir à implémenter une grille hexagonale (avec https://www.redblobgames.com/grids/hexagons/)
- [~] Réussir à implémenter une génération procédurale de map (génération organique -> [~] (car mal optimisé), bruit -> [ ])
- [X] Réussir à créer un système de sauvegardes qui tient la route un minimum
- [ ] Réussir à créer des IA basiques pour les joueurs adverses
- [ ] Résussir à créer un système correct pour les unités (pathfinding, combat...)
- [ ] Réussir à optimiser (éviter lag, éviter de prendre trop de place en mémoire...)
- [ ] Résussir à ne pas avoir trop de bugs
- [ ] Apprendre à bien organiser et commnenter le projet pour ne pas être complétement perdu quand on essaie de le continuer après une pause, ou quand un autre programmeur lit notre code
- [ ] Résussir à terminer un gros projet, à aller jusqu'au bout
